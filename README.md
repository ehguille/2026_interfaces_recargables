# 2026_interfaces_recargables
Ejemplo básico para practicar interfaces y herencia.

## Enunciado 

Una tarjeta puede ser de crédito, de débito o un monedero electrónico. Todos tienen un saldo máximo que no se puede modificar. Los monederos electrónicos pueden recargarse.

Un coche puede ser eléctrico o de combustión. Los coches eléctricos son recargables.

Recuerda: hacer uso correcto de paquetes, variables estáticas, etcétera.

Actualización: ahora, la batería es un objeto de los coches eléctricos.
